# Política de segurança

Não abra uma issue pública para vulnerabilidades ou possível exposição de dados.
Use um [GitHub Security Advisory privado](https://github.com/brunodias0903/splitfin/security/advisories/new)
e informe:

- área afetada e impacto estimado;
- passos mínimos para reprodução;
- versões ou commits afetados;
- sugestão de mitigação, se houver.

Não inclua credenciais ou dados financeiros reais. O recebimento será confirmado
assim que possível, e correções críticas terão prioridade sobre o roadmap normal.

Apenas a versão disponível na branch `main` recebe atualizações de segurança.
